# Macros (P-055) — 2026-11-07

Roadmap line (Part IV): *Macros: {{char}}, {{user}}, time/date,
random, and the mirrors' useful macro set — clean-room semantics,
documented.*

## What shipped

`src/runmal/prompt/macros.py` — one documented, pure-domain macro
engine for prompt text (no DB, no I/O, no network), plus the tools
API: `GET /tools/macros` (the registry) and
`POST /tools/macros/expand` (expand + full inspection report;
strict refusals surface as 422).

Syntax: `{{name}}` and `{{name::arg1::arg2}}`, names
case-insensitive, whitespace trimmed; `\{{...}}` escapes to a
literal; `<char>`/`<user>` angle aliases expand (context flag can
disable); a lone unclosed `{{` is not a token and stays
byte-identical. Expansion is a single pass — arguments are
literal text and expanded values are never re-scanned.

## The set

- **Identity:** char, user, persona (persona name, else user
  name), original (the pre-expansion text), model, chatId,
  lastMessage, lastUserMessage, lastCharMessage.
- **Clock** (injectable `now`, deterministic in tests): time,
  isotime, date, datetime, weekday, year, month, day, hour,
  minute, second.
- **Random:** `{{random::a::b::…}}` picks one choice;
  `{{roll::NdM}}` / `NdM+K` / `NdM-K` sums dice.
- **Variables:** getvar / setvar / addvar over a working copy of
  the caller's variable map (never mutated; final map returned
  on the report). `getvar` of an unset name is an error, never a
  silent empty string.
- **Transforms:** upper, lower, reverse, newline(::N), comment.

## Honesty contract

- **Random follows P-036's seeded-RNG discipline.** A seeded roll
  is a pure function of (algorithm `runmal-p055-macro-v1`, seed,
  roll context, occurrence index, raw macro text, die index) via
  SHA-256 — reproducible in isolation, forever. Every random
  expansion records a roll on the report: value, seed, seeded
  flag, choices/dice, outcome. `seed=None` draws system entropy
  and the record says `seeded: false` — inspectable after the
  fact, never reproducible, never disguised as seeded.
- **Unknown macros never silently vanish and never pass through
  disguised.** Report mode (default): they stay byte-identical in
  the output AND are listed in `report.unknown`. Strict mode:
  expansion raises `MacroError` naming every unknown and
  malformed macro in the text. Malformed known macros (bad dice
  spec, bad newline count, unset getvar, non-numeric addvar)
  follow exactly the same rule via `report.errors`.
- **Every successful expansion is recorded** (raw, name, args,
  value, kind) — the report is the inspector's evidence.

## Boundaries

- The legacy surfaces are untouched: S110 `substitute_macros`
  (card slots) and S307 `resolve_variables` (tools preview) keep
  their exact behaviour; macros.py is the engine for new callers.
  The lore engine's `{{lore:...}}` references and the context
  templates' `{{anchor}}` placeholders are different syntaxes
  owned by their own engines and are not consumed here.
- Wiring expansion into `compose()` itself is deliberately not
  in this slice: P-059 (prompt preview) is the natural consumer,
  and the engine + tools API are the delivered surface.
- No migration: macros are pure text expansion. Head stays 0033.
